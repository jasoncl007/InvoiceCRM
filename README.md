# 🚀 InvoiceCRM - Complete POS System

**InvoiceCRM** is a complete Point of Sale (POS) system for **Windows & Android** built with Flutter. Manage clients, generate invoices, track payments, and print receipts with thermal printer support.

---

## 📱 **Features**

| Feature | Status |
|---------|--------|
| ✅ Client Management (Add/Edit/Delete/Search) | Available |
| ✅ Invoice Generation with PDF | Available |
| ✅ Payment History Tracking | Available |
| ✅ Interactive Dashboard & Charts | Available |
| ✅ QR Code Scanner | Available |
| ✅ CSV Export for Reports | Available |
| ✅ Dark Mode Support | Available |
| ✅ Database Backup & Restore | Available |
| ✅ Thermal Printer Support | Available |
| ✅ Search & Filter | Available |

---

## 🛠 **Tech Stack**
1. Download InvoiceCRM.apk
2. Enable "Unknown Sources" in settings
3. Install APK
4. Open app from drawer

   🔧 Requirements
Windows:
Windows 10 or 11 (64-bit)

4GB RAM minimum

200MB free space

Android:
Android 8.0 or higher

2GB RAM minimum

50MB free space
